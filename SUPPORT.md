# Support

For questions about project scope, licensing or contributions, contact Miroslav Šotek, ANULUM, at protoscience@anulum.li.

The repository foundation is under construction. There is no released package, mixed-signal co-simulation service, installation support commitment or qualified coupled testbench. Do not rely on planned records for a boundary-interface, macromodel-fidelity, power-sequencing or reset-release sign-off decision.

For a technical report, provide the exact source revision, runtime environment, expected behaviour and minimal legally shareable input; never attach a customer design, a confidential macromodel or foundry deck or a simulation trace that is not public. Keep original outcomes and state which references or environments were unavailable. See [contributing](CONTRIBUTING.md).
